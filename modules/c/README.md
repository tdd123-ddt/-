# 模块 c · 温度指引生成

> 命题能力 c 的实现（全题"灵魂"）。输入模块 a 结构化病历 + 模块 b 痛点，生成
> **个性化、有温度、可执行**的健康指引。硬指标：≥3 病种、人工盲评"温度感"与
> "可行动性"平均 ≥ 4/5，且**非通用模板化**。

## 1. 动态章节（element 键固定，标题/数量/侧重由 LLM 定）

`element` 键是给评估/结构化用的固定 key（来自要素池），**但 title 由 LLM 口语化、
锚定病人的具体病/部位/事件**，章节数量与顺序不强制"六要素六段"：

| element | 标题（模板坏例，已禁用） | 个性化标题（正确示例） |
|---|---|---|
| diagnosis_plain | 您得的病，说人话 | 您肩膀里那根筋，磨破了 |
| treatment_review | 这几天您经历了什么 | 住院 3 天，肩上的手术怎么做的 |
| cost_explanation | 这次看病花了多少钱 | 3 万出头，医保报了 2 万，您自费 3 千 |
| recovery_plan | 接下来怎么养 | 回家头一个月，三件事最要紧 |
| psychological | 想对您说 | 等病理那几天最难熬，您不是一个人 |
| next_visit | 什么时候再来、什么情况要就医 | 3 周后复查，之后每 3 个月一次 |

扩展要素池（`schema.EXTRA_ELEMENTS`）：`recovery_wound`（伤口护理）/`recovery_activity`
（活动限制）/`recovery_diet`（饮食）/`diagnosis_tcm`（中医证型）。

**动态规则**：门诊小病可把"治疗回顾"合并进诊断；手术/住院"康复计划"加重、可拆成
伤口/活动/饮食多段；中医加"证型解读"；费用异常时"费用解读"与"心理安抚"可融成一段。

## 2. 反模板机制（对应红线）

1. **Prompt 强制**（`prompts/system_prompt.md`）：
   - "禁止通用科普"——删掉用户信息后仍成立的话就是模板，必须重写。
   - "必须锚定具体数字"——住院天数、费用、手术名、用药、复查时间。
   - "说人话"——把术语翻成大白话；"有温度"——第二人称、共情不评判。
   - **标题放开**——title 由内容长出来，禁照模板栏目名。
   - **开场白多样化**——交代具体事实 + 按病情严重度选情绪基调（重病安抚/小病轻快）。
   - **风格自适应**——按病情（癌症/慢病/小病）+ 年龄（老人慢白话、儿童转家长）定语气篇幅。
2. **回应痛点**：输入里带模块 b 的痛点，指引针对性回应（术语晦涩→讲透；自费高→算清账；
   缺指导→补康复计划；重复用药→温和提醒）。
3. **反模板自检 v2**（`generate.personalization_check_v2`）三指标：
   - `personalization_score`：引用了多少用户具体事实；
   - `title_similarity`：生成标题 vs 模板默认标题的相似度（越低越非模板，≥0.6 判模板化）；
   - `sentence_diversity`：各段开头是否雷同（是否每段都"您要/您应该…"祈使式）。
   - 综合 `anti_template_score`（0~1，越高越个性化）。

## 3. 盲评（温度感 + 可行动性，5 分制）

`evaluate.blind_evaluate`：跑 3 名"模拟盲评员"（LLM），按 5 分制 rubric 各打温度感、
可行动性，取均分。**LLM 初筛 + 人工复核**（对应 plan.txt 的盲评流程）。

实测：温度感 4.89 / 可行动性 4.56 / 总均分 **4.72**（≥ 4/5），个性化分数 1.0/0.9/1.0。

## 4. 使用

```bash
# 生成指引（输入模块 a JSON，自动读同目录模块 b 痛点）
python -m modules.c.run output/CL0300004715289963.json

# 生成 + 盲评
python -m modules.c.run output/CL0300004715289963.json --blind-eval

# 批量 3 病例 + 盲评 + 反模板自检
python _work/run_c_eval.py
```

输出：`output/<pid>.guidance.json`（结构化）、`<pid>.guidance.md`（可读版）、
`<pid>.guidance.scores.json`（盲评分）。
