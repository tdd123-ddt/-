# 网页版使用说明（理赔后医护关怀）

把「病历结构化 + 痛点识别 + 温度指引 + 品质画像」做成一个网页：
上传一个病人的病历图片文件夹，点一下按钮，自动生成全部信息。

================================================================
一、启动
================================================================

方式 A（推荐，双击即可）：
   双击项目根目录的「启动.bat」

方式 B（命令行）：
   在项目根目录执行：
       streamlit run app.py

启动后浏览器会自动打开（默认地址 http://localhost:8501）。
若没自动打开，把上面地址手动粘进浏览器即可。

> 首次运行会下载 OCR 模型文件（约几十 MB），请耐心等几秒；之后秒开。

================================================================
二、使用步骤（3 步）
================================================================

第 1 步：上传图片
   在「上传病历图片」区域，拖入或点选该病人的所有病历图片
   （出院小结、费用清单、门诊病历、发票等，jpg/png 都行，可一次多选）。

第 2 步：（可选）填病人 ID
   不填则自动生成一个临时 ID，不影响结果。

第 3 步：点「开始分析」
   页面会显示进度：① 结构化 → ② 痛点 → ③ 温度指引。
   跑完后自动切到结果页。

快速切换下一个病人：
   点「开始分析」旁边的「清空上传」按钮，一键清掉已上传的图片和上一个病人的结果，
   直接传下一份病历即可。

================================================================
三、四个页签怎么看
================================================================

【📋 结构化结果】
   - 顶部是一张「关键事实摘要表」：患者 / 医院科室 / 就诊时间 / 诊断 / 手术 / 费用，一眼看完。
   - 点「查看完整结构化 JSON」展开全量字段（含字段级置信度与证据溯源）。

【⚠️ 就医痛点】
   - 每张卡片 = 一个痛点，左侧色条表示严重度：
       红 = 高（明显危害/多花钱）、橙 = 中（值得提醒）、黄 = 低（轻微/疑似）。
   - 卡片上有大类徽章（临床/费用/体验）+ 一句话理由 + 可溯源的证据。

【💌 温度指引】
   - 渲染成一封"蓝色信笺"：诊断说人话 / 治疗回顾 / 费用解读 / 康复计划 / 心理安抚 / 下次就医。
   - 全部锚定这个病人的具体数字（住院天数、自费金额、手术名、复查时间），非通用科普。
   - 底部提示本次引用了哪些个性化事实。

【🏥 品质画像】
   - 顶部先显示「当前上传病例」的单病例画像（按你上传的病种实时计算，如肠胃炎）。
   - 展开「跨病历品质画像库」，点「生成 / 刷新画像库」后，你上传的病例会被纳入，
     并自动为它的病种生成同行机构做对比（同行机构为合成估算，已标注"合成"）。
   - 每个病种一张可排序表格（均次费用/住院天数/自费比例/用药合理率/治疗规范率/再入院率/满意度），
     下面是可解释推荐（每条 ≥2 条可量化理由）。
   - 每家机构旁有「🔍 搜索公开评价」按钮，联网搜索该医院/医生的公开口碑与专家信息
     （结果标注"仅供参考，可能与实际不符"；知名机构结果更全，小机构可能较少）。

================================================================
四、配置（API key）
================================================================

LLM 抽取走项目根目录 `.env`（DeepSeek 的 Anthropic 兼容端点，已填好）。
要换 key / 换模型，编辑 `.env`：

   ANTHROPIC_API_KEY=你的key
   ANTHROPIC_BASE_URL=https://api.deepseek.com/anthropic
   ANTHROPIC_MODEL=deepseek-chat

若 `.env` 里没有 key，网页顶部会黄条提醒，并自动退回"纯规则模式"
（费用/日期等确定性字段仍能出，诊断/用药等语义字段会缺失）。

================================================================
五、常见问题
================================================================

Q1：点开始分析后一直转圈？
   → 首次要下载 OCR 模型；或 LLM 网络慢。看浏览器页面上的进度提示到哪一步。

Q2：提示"未检测到 API key"？
   → 检查项目根目录是否有 .env、里面 key 是否正确。

Q3：识别结果不完整 / 缺失率高？
   → deepseek-chat 偶发返回不完整；把 .env 里 ANTHROPIC_MODEL 换成原生 Claude
     （claude-sonnet-5-5，并删掉 ANTHROPIC_BASE_URL 行）可明显提升。

Q4：上传了图片但没识别出任何文字？
   → 图片太糊/歪斜会影响 OCR。换清晰、正向的图再试。

Q5：品质画像里为什么有"合成"数据？
   → 真实病例只有 3 个，不够"每病种 5 家机构"。模块 d 用确定性合成数据补齐机构覆盖
     （表里标注"真实+合成"的是含真实病例的机构）。接入真实多机构数据后可替换。

================================================================
六、注意事项（合规）
================================================================

- 医疗数据敏感：本工具仅在演示/授权范围内使用；生成内容含具体剂量与复查时间，
  对外展示前请二次脱敏，并加"仅供健康参考，具体遵医嘱"的免责声明。
- 温度指引是 AI 生成，不能替代医生意见。
