# 理赔后医护关怀 —— 项目运行说明（README）

上传病历图片，一键生成四类结果：**结构化病历**、**就医痛点**、**温度指引**、**品质画像**。

---

## 一、环境依赖

| 依赖 | 版本要求 | 说明 |
|------|----------|------|
| Python | ≥ 3.10（推荐 3.11） | 3.13 亦可运行，OCR 兼容性以 3.11 最稳 |
| streamlit | ≥ 1.30 | Web 界面框架 |
| rapidocr-onnxruntime | ≥ 1.2.0 | 病历图片 OCR（首次运行自动下载模型，约几十 MB） |
| pydantic | ≥ 2.0 | 数据结构校验 |
| anthropic | ≥ 0.40 | 调用 DeepSeek 的 Anthropic 兼容端点做 LLM 抽取 |
| requests | ≥ 2.25 | HTTP 请求（联网搜索公开评价） |
| pillow | ≥ 9.0 | 图像处理 |

> 全部依赖已在 `requirements.txt` 中声明。

---

## 二、安装步骤

```bash
# 1. 进入项目根目录
cd 项目目录

# 2. 安装依赖（推荐默认 PyPI 源；清华镜像可能报 "No matching distribution found"）
python -m pip install -r requirements.txt
```

> 注意：`rapidocr-onnxruntime` 会拉取 `onnxruntime`、`opencv-python` 等大包（合计 100MB+），首次安装需数分钟，属正常现象。

---

## 三、一键运行

**方式 A（Windows 双击）**：双击项目根目录的 `启动.bat`。

**方式 B（命令行）**：

```bash
python -m streamlit run app.py
```

启动后浏览器自动打开 `http://localhost:8501`；未自动打开则手动访问该地址。

---

## 四、使用步骤（3 步）

1. **上传图片**：拖入或点选病人的病历图片（出院小结、费用清单、门诊病历、发票等，jpg/png 均可，支持多选）。
2. **（可选）填病人 ID**：留空则自动生成临时 ID。
3. **点「开始分析」**：页面依次显示 ① 结构化 → ② 痛点 → ③ 温度指引，完成后自动切换结果页。

四个结果页签：
- **📋 结构化结果**：关键事实摘要表 + 完整 JSON（含字段级置信度与证据溯源）
- **⚠️ 就医痛点**：按严重度分色（红=高/橙=中/黄=低）的痛点卡片，含证据
- **💌 温度指引**：蓝色信笺式「诊断说人话/治疗回顾/费用解读/康复计划/心理安抚」
- **🏥 品质画像**：单病例画像 + 跨病历品质画像库（含同行机构对比）

---

## 五、配置（API key）

LLM 抽取走项目根目录 `.env`（已填好 DeepSeek 的 Anthropic 兼容端点，开箱即用）：

```
ANTHROPIC_API_KEY=sk-xxxx
ANTHROPIC_BASE_URL=https://api.deepseek.com/anthropic
ANTHROPIC_MODEL=deepseek-chat
```

- 换模型：改 `ANTHROPIC_MODEL`（如换成原生 Claude `claude-sonnet-5-5`，并删除 `ANTHROPIC_BASE_URL` 行）。
- **未配置 key 时**：页面顶部黄条提醒，自动退回「纯规则模式」——费用/日期等确定性字段仍可输出，诊断/用药等语义字段缺失。

---

## 六、预期输出样例

**输入**：1 张出院小结图片（含诊断、手术、费用、住院天数）。

**输出**（`output/` 目录持久化 `{pid}.json`，网页四页签展示）：
- 结构化结果：患者 / 医院科室 / 就诊时间 / 诊断 / 手术 / 费用等字段，附置信度
- 就医痛点：如「自费比例偏高」「住院天数长于同类病例」等，带证据与严重度
- 温度指引：锚定具体数字（住院天数、自费金额、手术名、复查时间）的个性化信笺
- 品质画像：该病种的均次费用 / 住院天数 / 自费比例等指标，及可解释推荐

> 真实病例仅 3 个，品质画像库用确定性合成数据补齐机构覆盖（表中标注"真实+合成"）。

## 七、常见问题

| 问题 | 原因与解决 |
|------|-----------|
| 双击 bat 报 `streamlit 不是内部或外部命令` | 用 `python -m streamlit run app.py`（模块方式），不要裸调 exe |
| 双击 bat 报 `Failed to install dependencies` | 系统 PATH 无真实 Python；确认已装 Python 3.10+ 并勾选 Add to PATH |
| 卡在 `Email:` 提示 | Streamlit 首次运行引导，直接回车即可 |
| 点分析一直转圈 | 首次下载 OCR 模型 / LLM 网络慢，看进度提示 |
| 识别结果不完整 | 图片模糊或歪斜；换清晰正向图，或换原生 Claude 模型 |

## 九、代码结构（技术架构）

```
app.py                   # Streamlit 入口（上传/触发 → 分析 → 五页签展示）
web/
  runner.py              # 全链路编排：a(结构化) → b(痛点) → c(温度指引)，LLM 失败自动降级规则模式
  ui.py                  # 结果渲染
  search.py              # 联网搜索公开评价（Bing + LLM 兜底）
modules/
  a/                     # 模块 a：病历结构化（OCR + LLM 抽取 + 规则）
  b/                     # 模块 b：就医痛点识别
  c/                     # 模块 c：温度指引生成
  d/                     # 模块 d：品质画像（聚合 + 合成对比 + 推荐）
output/                  # 结构化结果持久化目录（跨病历聚合用）
```

**数据流**：上传图片 → 落盘临时目录 → 模块 a 结构化 → 模块 b 痛点 → 模块 c 指引 → 四页签渲染；模块 d 独立聚合 `output/` 下所有病例做品质画像。
