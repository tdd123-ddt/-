# DESIGN.md — 医护洞察与温度指引引擎 · 答辩 PPT 设计稿

## 风格定位

科技克制 / 数据驱动 / 医疗温度 / 严谨可信。医疗 AI 主题，采用科技蓝 + 温暖青作为主色，白底为主、深色块用于 Hero 页聚焦。

## 画布与母版（1280×720）

| 母版区 | 位置 | 高度 | 内容 |
|--------|------|------|------|
| A 标题块 | 0–120px | 120px | 主标题 36px bold |
| B 内容区 | 120–660px | 540px | 正文/图表/配图/卡片 |
| C 页脚条 | 660–720px | 60px | 左"医护洞察与温度指引引擎" + 右页码 NN/12，14px 灰 |

页面左右 padding 60px，上下 padding 20px。封面/章节扉页/结束页可用自定义版式（省略 C 区）。

## 颜色系统（≤4 hex）

| 角色 | hex | 用途 |
|------|-----|------|
| 主色（科技蓝） | `#2B6CB0` | 标题栏、色块、章节背景 |
| 辅色（温暖青） | `#38B2AC` | 卡片背景、图表第二系列 |
| 强调色（深蓝） | `#1A365D` | 巨型数字、核心数据标注、Hero 页深色块 |
| 中性色 | `#1A1A1A`（文本）/ `#F7FAFC`（浅底）/ `#E2E8F0`（分隔） | 正文、页脚、边框 |

**色彩面积分配**：主色 ≤ 60%、辅色 ≤ 30%、强调色 ≤ 10%（Hero 页强调色可到 15-20%）。

**渐变方案**：`linear-gradient(135deg, #2B6CB0 0%, #38B2AC 100%)` 用于章节扉页背景、卡片头部。

## 配图系统

- **L1 主视觉**（封面/章节扉页背景）：用 ImageGen 生成 3 张（封面 + 3 章节扉页共 4 张，风格统一为"医疗科技插画，蓝青渐变，抽象数据流"）。
- **L2 支撑图**：架构图/三层抽取/画像维度/触达闭环，用 SVG 结构化图形（流程/架构属低语义结构化元素，允许 SVG）。
- **L3 徽标**：全篇页脚条左侧统一放"医护洞察与温度指引引擎"文字，无图形角标。

生图风格统一词：`minimal medical technology illustration, abstract data flow, soft blue-cyan gradient, clean white background, no text`
