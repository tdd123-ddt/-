# 理赔医护关怀引擎 —— Demo 下载与启动指南

> 赛道四·课题二：基于理赔医护记录的「医护洞察与温度指引」引擎

## 快速开始（评委版）

**第 1 步 · 下载**
到本仓库的 [Releases](../../releases) 页面，下载最新版本的
`理赔医护关怀引擎_demo.zip`（约 215 MB）。

**第 2 步 · 解压**
解压到任意目录（建议路径不含中文空格即可，中文目录名本身没问题）。

**第 3 步 · 双击启动**
双击 `启动.bat`，浏览器自动打开 http://localhost:8501 。

就这么简单——**无需安装 Python、无需安装任何依赖、无需联网装包**。

## 为什么能零配置启动

本 demo 是「绿色版」，目录里内置了：

| 组件 | 说明 |
|---|---|
| `runtime/` | 内置 Python 3.13 解释器 + 全部依赖（streamlit / rapidocr-onnxruntime / anthropic / openpyxl 等） |
| `output/` | 79 个真实结构化病例 + RAG 问答库（38846 问答对） |
| `.env` | 内置演示用 LLM key（DeepSeek Anthropic 兼容端点，开箱即用） |

唯一需要联网的环节是 **LLM 生成**（调用 DeepSeek API）；OCR、规则、RAG 检索均本地离线完成。

## 演示路径建议

**推荐：模拟理赔结案事件（离线、最稳）**
1. 启动后，选择「演示模式 → 模拟理赔结案事件」
2. 从内置 79 个真实病例中下拉选择一个（如肺癌病例）
3. 点「模拟核赔通过」，自动触发完整链路：
   理赔触发 → 结构化(模块a) → 痛点识别(模块b) → 温度指引(模块c) → 品质画像(模块d) → 关怀增强(模块e)

**可选：现场拍照 OCR**
上传清晰的出院小结 / 费用清单图片，走「上传病历图片」路径。

## 常见问题

**Q：双击启动.bat 没反应 / 报错？**
确认已完整解压（尤其 `runtime/` 目录不能缺），不要直接在压缩包里运行。

**Q：杀毒软件拦截 python.exe？**
内置 python.exe 可能被误报，选择「允许/信任」即可。

**Q：识别结果缺失？**
换更清晰的图片，或改用演示模式的内置病例。

**Q：想换自己的 LLM key？**
编辑 `.env` 里的 `ANTHROPIC_API_KEY`。
