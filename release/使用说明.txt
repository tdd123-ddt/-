========================================
 理赔后医护关怀引擎 —— 评委版使用说明
========================================

【零配置 · 一键启动】

  本文件夹是「绿色版」，已内置 Python 运行时和全部依赖，
  评委老师电脑上【无需安装 Python、无需联网装依赖】。

  启动方法：双击「启动.bat」即可。
    - 浏览器会自动打开 http://localhost:8501
    - 若未自动打开，手动在浏览器地址栏输入该地址即可

【演示环境要求】
  - Windows 7/10/11 均可（本文件夹内置 64 位 Python 3.13）
  - 联网（LLM 调用 DeepSeek API 生成内容时需要）
  - 无需安装任何软件

【演示 3 步】
  1. 上传病历图片（出院小结/费用清单/门诊病历/发票，jpg/png，可多选拖拽）
  2. 点「开始分析」
  3. 查看结果页（结构化结果 / 就医痛点 / 温度指引 / 品质画像 / 关怀增强）

【演示建议】
  - 推荐用「演示模式」下的「模拟理赔结案事件」入口，从内置的
    79 个真实结构化病例中下拉选择一个，点「模拟核赔通过」，
    可完整演示「理赔触发 → 四/五模块自动运行」的闭环，无需现场拍照。
  - 若现场拍照演示，优先选清晰的出院小结或费用清单，识别效果最好。

【目录说明】
  runtime/      内置 Python 解释器 + 全部依赖（勿删）
  app.py        网页入口
  modules/      五个核心模块（a结构化/b痛点/c温度指引/d品质画像/e关怀增强）
  output/       内置演示数据（79 个真实结构化病例 + RAG 问答库）
  答辩PPT/      答辩演示文稿（13 页）
  技术方案文档.md  完整技术方案
  验收项自检表.md  验收项对照

【常见问题】
  Q: 双击启动.bat 没反应？
     → 确认文件夹已完整解压（尤其 runtime/ 目录），不要放在压缩包里直接运行。
  Q: 提示 360/杀毒拦截？
     → 内置 python.exe 可能被误报，选择「允许/信任」即可。
  Q: 识别结果缺失率高？
     → 换清晰、正向的图片；或换演示模式的内置病例。
  Q: 想换自己的 API key？
     → 编辑 .env 文件里的 ANTHROPIC_API_KEY。

【合规提醒】
  本工具处理医疗数据，仅在演示/授权范围内使用；生成内容为 AI 产出，
  仅供参考、不能替代医生意见，对外展示前请二次脱敏。
